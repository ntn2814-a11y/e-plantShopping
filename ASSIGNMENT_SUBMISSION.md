## Upload through the GitHub website

1. Extract `Paradise-Nursery-React-Project.zip`.
2. On GitHub, create a **public** repository named `paradise-nursery`.
3. Choose **uploading an existing file** and drag every extracted file and folder into the upload area.
4. Commit the files to the `main` branch.
5. Open each link above after replacing `YOUR-USERNAME`, confirm that the code is visible without signing in, and paste it into the corresponding answer field.

If you use a different repository name or branch, replace `paradise-nursery` or `main` in all seven URLs.
